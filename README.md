# Benny Bunny's Garden

A colorful, child-friendly 10-mini-game browser game built with Vite. It includes:
- Character selection
- Garden map with 10 unlockable mini-games
- Stars and sticker rewards
- Persistent progress with localStorage
- Unlockable Benny Bunny outfits/accessories
- Simple sound effects and music toggle
- Responsive mobile-friendly UI

## Run locally
npm install
npm run dev

## Deploy to Vercel
Upload this project to a Git repository and import it into Vercel, or deploy the folder with the Vercel CLI.

No backend or environment variables are required.
